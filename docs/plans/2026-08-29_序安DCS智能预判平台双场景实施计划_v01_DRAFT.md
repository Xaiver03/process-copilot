# 序安·DCS 智能预判平台双场景实施计划 v01

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将现有“序安 Process Sentinel”升级为可跨工业场景复用的“序安·DCS 智能预判平台”，保留连续化工 TEP 场景，并把污水处理出水风险预判设为当前默认演示，跑通工业模型、语言模型、人工决策、审计和影子写回的完整链路。

**Architecture:** 统一采用“DCS/传感器时序输入 → 数据质量与时间对齐 → 场景专属工业模型 → 风险事件与变量证据 → 语言模型解释/追问 → 人工确认 → 审计 → 受控写回预演”的骨架。TEP 保留现有在线 PCA/HGB 推理；污水场景使用 UCI Water Treatment Plant 公开数据训练下一化验周期软测量模型，并通过同一事件接口接入现有前后端。Demo 保持只读，生产版写回必须经过人工审批、权限、联锁、网关和回读。

**Tech Stack:** Python 3.12、scikit-learn、FastAPI、PostgreSQL、Next.js/React/TypeScript、Vitest、Playwright、Docker Compose、XeLaTeX、PPTX。

---

## 产品与事实边界

- 品牌：`序安`。
- 产品名：`序安·DCS 智能预判平台`。
- 一句话定位：基于 DCS 时序数据，提前预测工业过程风险，给出原因证据和处置建议，并由人确认闭环。
- 默认场景：污水处理出水风险预判。
- 保留场景：连续化工过程偏移预警（TEP）。
- 用户确认的现场事实：DCS/传感器接口已经存在；AI 的价值是补齐离线采样与化验滞后，不是重复建设采集系统。
- 当前演示事实：使用公开数据/仿真数据，不代表贵州企业生产数据或现场效果；系统只读，`sent=false`。
- 任何历史分位边界必须标注为“公开数据历史边界”，不得称为法规排放限值。
