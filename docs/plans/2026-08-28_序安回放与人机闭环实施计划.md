# 序安回放与人机闭环 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 把静态回放页升级为数据会推进、异常会触发、人员能追问和预演受控写回的中文 Demo。

**Architecture:** 由前端确定性回放时钟驱动当前样本与热力图可见窗口，保持后端契约不变；事件页增加事件证据驱动的本地问答和只读写回预演。展示层按故障编号中文化，不改底层数据。

**Tech Stack:** Next.js、React、TypeScript、Vitest、Testing Library、ECharts、Playwright。

---
