# 序安黑客松路演 PPT 实施计划

> **For Codex:** REQUIRED SUB-SKILL: 使用 `pptx` 与 `Presentations`，按任务顺序执行并在每个阶段提交。

**Goal:** 基于公开 TEP 数据、现有序安产品事实、真实部署/测试证据和贵州磷化集团“1468”官方公开案例，制作 10 页中文黑客松路演 PPT，并交付可编辑 PPTX、PDF 与逐页 QA。

**Architecture:** 叙事采用“现场堵点 → 事故前偏移 → AI 证据 → 人工确认 → 当前只读边界 → 受控写回未来 → 公开数据与可复现证据 → 现场 Demo → PoC”闭环。演示文稿由 `@oai/artifact-tool` 的 JavaScript ES Module 构建，品牌 token、Logo 主视觉和产品截图作为事实资产嵌入；可编辑文字、形状、流程与时间轴保留为 PowerPoint 原生对象。

**Tech Stack:** `@oai/artifact-tool`、Node.js 运行时、LibreOffice/Poppler、Presentations QA 工具、Git。

**Files:**

**Steps:**
