# 连续化工过程偏移副驾驶 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use `executing-plans` or `subagent-driven-development` to implement this plan task-by-task.

**Goal:** 从零构建一个可公开演示的连续化工过程偏移副驾驶，完成 TEP 数据回放、偏移发现、故障研判、Top-3 证据、处置建议、人工确认、审计记录与单机部署。

**Architecture:** Next.js Web 通过 REST + SSE 访问 FastAPI 模块化单体。Parquet 保存时序与预计算推理结果，PostgreSQL 保存回放、事件、决策和审计；LLM 是可选改写层，主链路必须离线可用。

**Tech Stack:** Next.js、TypeScript、React、Apache ECharts、Vitest/Playwright、FastAPI、Pydantic、SQLAlchemy、PostgreSQL、PyArrow、NumPy、scikit-learn、pytest、Docker Compose、Caddy/Nginx。
