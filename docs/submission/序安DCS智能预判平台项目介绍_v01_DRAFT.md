# 序安·DCS 智能预判平台项目介绍

状态：`DRAFT`
版本：`v01`
日期：`2026-08-29`

## 一句话介绍

**序安·DCS 智能预判平台**基于 DCS 时序数据，提前预测工业过程风险，给出原因证据和处置建议，并由人确认闭环。

## 1. 我们解决什么问题

工业现场往往已经有 DCS 在线变量，但关键出水质量判断还要等待离线化验结果。问题不只是“有没有数据”，而是在线过程信号与滞后的化验标签没有被及时对齐：当结果出来时，异常窗口可能已经过去，工程师也缺少一条可追溯的判断路径。

平台不再造一套采集系统，而是在现场已有 DCS 接口的基础上，把在线变量与离线化验标签对齐，面向未来化验周期输出出水风险预测，并说明：

- 风险是否正在形成或持续；
- 哪些变量是主要证据；
- 还需要核对哪些工况、设备或操作条件；
- 谁确认了建议，后续如何复盘。

## 2. 默认场景：污水出水风险预测

默认 Demo 讲述污水场景。平台读取已有在线过程变量，在时间对齐后预测未来化验周期的出水风险，输出风险趋势、候选原因证据和待核查事项。输出是**风险预测**，不是对已经超标的实测判定；最终结果仍需以现场化验、工艺核验和合规流程为准。

```text
DCS 在线变量
  -> 数据质量与时间对齐
  -> 未来化验周期风险预测
  -> 变量证据与待核查项
  -> 人员确认/驳回
  -> 审计记录与复盘
```

如果使用公开 UCI Water Treatment Plant 数据进行方法说明，应明确：UCI 官方描述为 527 个日记录、38 个变量，1993 年捐赠，许可为 CC BY 4.0；本地镜像实际为 520 条非空记录且含缺失。该公开数据用于方法与数据处理演示，不应写成客户现场数据或污水厂实时生产数据。

## 3. 切换场景：TEP 连续化工过程偏移

平台保留 TEP 作为连续化工切换场景，用于演示另一类过程风险研判：

```text
公开 TEP 仿真回放
  -> PCA T²/SPE 发现持续偏移
  -> 候选故障排序
  -> Top-3 变量贡献证据
  -> 确定性处置建议
  -> 人工确认与审计
```

该场景中的 41 个测量变量、11 个操纵变量、公开仿真故障和冻结模型，只能证明一条可复现的演示链路。TEP 不是污水现场数据，也不代表真实磷化工装置的压力、温度、原料、控制逻辑或生产指标。

## 4. 产品如何工作

### 数据对齐

平台接入既有 DCS 时序数据，对变量字典、采样周期、时间戳和数据质量进行核对，再与离线化验项目的采样时间、出结果时间和标签窗口对齐。缺失、冻结、异常时间戳或标签不完整时，系统应降低结论强度并提示人工核对。

### 风险预判

污水场景重点预测未来化验周期的出水风险；TEP 场景重点识别持续过程偏移。平台不把单个异常点直接包装成确诊，不把模型候选写成已经发生的事实。

### 原因证据

界面展示趋势、变量贡献、候选原因和待核查事项。证据用于缩短排查路径，不单独证明根因；人员可确认、驳回或补充现场结果。

### 人工闭环

当前 Demo 是只读/影子建议，事件发送状态为 `sent=false`。处置建议必须由人确认并留痕；平台当前不向 DCS、PLC、联锁或控制回路自动写回。

## 5. 为什么现在值得做

- 现场已有 DCS 接口，第一步可以围绕既有数据链路开展，而不是先改造采集层。
- 在线变量与滞后化验标签之间存在可利用的时间差，适合用时序建模支持提前研判。
- 部分同集团公开废水指标存在手工/月度监测旁证，说明质量管理已有周期性记录基础；这不是实时部署或模型效果证明。
- HJ 1480-2026 将于 2026-10-01 实施，并强调重点监测点视频联网，可作为监测数字化趋势的背景；平台不据此宣称已完成现场视频部署或合规验收。

## 6. 交付与验证路径

1. **数据对齐：** 核对 DCS 变量字典、采样周期、时钟、化验项目和标签窗口。
2. **离线回放：** 用历史数据建立装置自己的基线，按时间切分进行盲测。
3. **影子运行：** 先只读运行 4–8 周，由工艺人员确认事件和处置结果。
4. **事件级验收：** 评估误报、漏报、检测延迟、告警重复和人工处置时间；在数据不足时不填充具体数值。
5. **受控路线：** 只有在安全审查、权限控制、审批和可回滚机制完成后，才讨论生产写回。写回不是当前 Demo 能力。

## 7. 项目边界

本项目当前不宣称：

- 已在真实企业生产现场完成部署或持续运行；
- 已取得某个准确率、召回率、提前量、ROI 或安全收益；
- 能替代离线化验、工程师确认或监管判定；
- 能证明某次环评预测已经被现场实测验证；
- 已部署现场视频、无线传感器或其他未确认的硬件；
- 能自动操作阀门、联锁、PLC、DCS 或控制回路；
- 四川 DCS 规格、其他磷化工案例或交椅山材料就是当前客户现场参数和验证结果。

## 8. 现场演示看点

1. 在默认污水场景中，展示在线变量与未来化验周期之间的时间对齐关系。
2. 展示风险趋势、主要变量证据和待核查事项，而不是只亮一个红灯。
3. 切换到 TEP 场景，展示持续偏移、候选故障和 Top-3 变量证据如何形成研判链路。
4. 完成人工确认或驳回，生成审计记录。
5. 明确显示“只读建议”“`sent=false`”“不写回控制系统”。

## 9. 下一步待现场确认

- DCS 与时序库的实际接口、变量字典和可读取时间范围；
- 在线变量的采样周期、时钟同步、缺失与维护标记；
- 离线化验项目、采样时间、出结果时间、检测方法和标签覆盖；
- 未来化验周期的业务定义与预警窗口；
- 运行工况、开停车/切换阶段和异常事件的分段规则；
- 监测点、排放口、工艺单元与变量之间的映射；
- 班组确认、驳回、处置和复盘流程；
- 账号权限、审计要求、安全审查和未来写回的审批边界。
