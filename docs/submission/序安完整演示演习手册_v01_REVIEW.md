# 序安 Process Sentinel 完整演示演习手册 v01

状态：`REVIEW`

公网入口：<https://huagong.finlaw.cloud/demo>

适用：黑客松评审、产业方演示、PoC 前沟通

主链路：管理预检 → 过程回放 → 偏移事件 → AI 追问 → 人工决策 → 审计留痕

## 1. 演示必须讲清的事实

- 当前数据是 Tennessee Eastman Process（TEP）公开化工过程仿真数据，不是贵州真实工厂数据。
- PCA / HGB 工业模型由 Worker 按样本在线推理；结果不是页面上预先写死的红灯。
- 语言模型是事件解释增强层。公网未启用时，页面必须明确显示“模板降级”，不能说成在线大模型回答。
- 管理后台包含运行概览、AI 配置、调用记录和配置审计。公网可查看，危险配置写入与连接测试默认禁用。
- 当前 Demo 只读，不向 APC、DCS、PLC 或联锁系统写回。
- 未来可做受控写回，但必须经过人工发起、权限校验、工艺上下限、联锁校验、人工二次确认、受控网关和失败回滚。

## 3. 人员分工

- 主演示人：讲问题、控鼠标、发起追问、提交人工结论。
- 演示助手：提前登录、记录新 run URL、监看 Worker / API / SSE，不在主演示时抢操作。
- 故障接管人：准备第二个浏览器、新 run、事件直链、本地服务和产品手册 PDF。

## 4. 演示前 10 分钟预检

### 4.1 公网与界面

- [ ] 打开 `/demo`、`/replay`、`/system`，页面无水平溢出、无组件重叠。
- [ ] 使用 `system-admin` 登录，能进入 `/admin`。
- [ ] `/admin` 显示 Worker 就绪、工业模型 `tep-pca-hgb-online-v01` 就绪。
- [ ] 语言模型状态与实际一致；如为离线，降级原因清楚可见。
- [ ] `/admin/ai` 能读取配置，密钥不回显。公网不执行保存或连接测试。

### 4.2 真实回放

- [ ] 选择“进料组成阶跃偏移（故障 1）”并点“开始回放”。
- [ ] 回放创建后设为 `20×`，当前样本从 0 持续增长。
- [ ] 页面出现当前 run 的“进入事件研判”链接。
- [ ] 记下 run ID 和 event ID；刷新后仍能通过 URL 打开。

### 4.3 人机交互与留痕

- [ ] 在事件页追问“为什么不是传感器故障？”。
- [ ] 回答显示模式、模型、证据变量和 Trace ID。
- [ ] 切换班长或工艺工程师账号，提交一次“确认 / 驳回 / 升级”和研判说明。
- [ ] 打开事件记录，核对操作者、结论、模型版本、Trace ID 和时间线。
- [ ] 再使用管理员登录，在 `/admin/interactions` 找到本次追问。

## 6. 故障演练

### 语言模型不可用

- 动作：继续走工业模型主链路，指出“模板降级”标签。
- 口径：“事件检测和证据仍来自在线工业模型；当前语言层使用确定性模板降级，没有伪装成在线大模型。”

### 回放样本不推进

- 动作：停止继续点页面；检查 `/admin` 的 Worker 状态、run 状态和 SSE；必要时新建 run。
- 禁止：不用旧事件冒充当前 run，不声称“其实后台在跑”。

### SSE 中断

- 动作：不要硬刷新页面；等待客户端自动重连，并观察它携带最后消息游标继续订阅。若自动重连失败，再新建 run。
- 验收：页面保留当前 run，不重复产生同一样本的事件，当前样本继续增长。

### 公网不稳定

- 动作：转入已预检的本地 Compose 环境，仍从新 run 开始。
- 口径：明确说“当前为本地同版应用”，不假装公网没有故障。

## 7. 不得宣称

1. 不得说使用了贵州真实工厂数据或已完成真实装置验证。
2. 不得给出未经现场验证的误报率、漏报率、固定提前量、经济或安全收益。
3. 不得把“模板降级”说成在线大模型。
4. 不得说公网管理员可以任意修改 Provider 或测试企业内网连接。
5. 不得说当前系统会自动写回 PLC / DCS；当前只有受控写回流程预演。
